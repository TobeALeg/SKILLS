五条铁律

  1. border-radius 只用 2px，不要圆角
  2. 不用阴影，靠分割线和留白区分层级
  3. 只有 rust 一个强调色，不引入其他彩色
  4. 字重克制：正文 400/500，标题 600/700
  5. 间距宽松：宁可多留白，不要挤
